# templates/fari

Il faro: uno schema oppure un MONDO (cartella con `level.dat`) che contiene la costruzione.

- **Formati**: schemi, o cartelle-mondo
- **Opzione**: `--templates-faro`; senza, il faro e' disegnato da codice. Per un mondo serve un `meta.json` con la `regione` (x0, y0, z0, x1, y1, z1) e `terreno_y`.

Il contenuto di questa cartella **non e' nel repository**: sono schemi scaricati o
acquistati, di altri autori, e il repository e' pubblico. Metti qui i tuoi file in
locale; git li ignora (vedi `.gitignore`).
