# templates/moli

Il molo: una banchina con una piccola abitazione, che si posa sulla riva vicino agli abitati di costa.

- **Formati**: `.schematic`, `.schem`, `.nbt`
- **Opzione**: `--templates-molo`; senza, il molo e' disegnato da codice. Serve un `meta.json` con `terra` (il verso del modello verso terra, es. "+x"), `costa_x`, `centro_z` e `linea_acqua`.

Il contenuto di questa cartella **non e' nel repository**: sono schemi scaricati o
acquistati, di altri autori, e il repository e' pubblico. Metti qui i tuoi file in
locale; git li ignora (vedi `.gitignore`).
